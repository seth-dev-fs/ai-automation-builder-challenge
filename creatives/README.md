# creatives/

Saídas do **Agente de criativo** (Agente 2), geradas pelo pipeline no GitHub
Actions a partir dos clusters em `analysis/`.

Um ficheiro por criativo (ex. `cr_new_01.md`), com pelo menos:

- **tema / dor ou elogio** que o criativo trabalha
- **ângulo** do anúncio
- **copy** (headline + corpo)
- **prompt de imagem** (gerar a imagem em si é opcional)
- uma **tag/UTM** que torne o criativo rastreável até ao resultado

Devem ser **commitados pelo workflow**, não à mão.
